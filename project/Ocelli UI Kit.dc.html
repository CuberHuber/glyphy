Ocelli

A nine-cell dot matrix. Every cell is either a bare dot or a ringed dot; the pattern of rings over time is the whole language. Hand-drawn origin, kept deliberately uneven — clean stroke, wobbly path.

06

Do & don't

DO

Keep the square box and the nine-cell lattice intact at every size.

DON'T

Stretch, skew or non-uniformly scale. The wobble is the only distortion allowed.

DON'T

Mix fills or colour cells individually. One ink, one fill, per mark.

DON'T

Run several animated marks in one view. One moving glyph per screen, maximum.

/>
variant7 motion states + static
size16–320px; derives stroke and dot
inksingle colour, hex; tint = ink @ 18%
fillstroke for motion, tint for completed
dotsoff below 24px

Rings are CSS borders with irregular border-radius per cell, not paths — so the mark stays crisp at any size and the wobble costs nothing. No SVG, no sprite sheet.
